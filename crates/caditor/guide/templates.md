# Templates and model properties

## Templates

A template is a model that new models start from: its parameters, sketches, features, saved views
and properties. {command:file.save_as_template} saves the current model as one.
{command:file.new_from_template} starts an untitled copy of a template, so the template itself is
never changed by editing.

In [Preferences](preferences) › General › New models, **Start from** makes {command:file.new} start
from a template of your choice.

## Model properties

{command:file.properties} holds the model's title, part number, revision, author, organisation,
description and notes. They are kept in the file and written into exports that have room for them, such as STEP and
3MF; the notes stay in the model.
